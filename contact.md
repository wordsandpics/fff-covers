## Report a tutorial problem

Use the [GitHub issues page](https://github.com/wordsandpics/fff-covers/issues) for incorrect instructions, broken downloads, generator problems, and feature suggestions. Include the page you were following and what happened.

## Share a recipe or tip

If you have found a useful way to clean up metadata, calculate a column, select a cover, or handle an unusual edge case, I would love to hear about it. Share it through the GitHub issues page or one of the contact options below. Please explain what the recipe does, where the code belongs, and any limitations you have noticed so other readers can use it safely.
