## Before importing

ZIP files serve different purposes. Do not import the background pack as a Generate Cover preset, and do not unzip the preset before importing it. Keep a backup of your existing code before replacing a customized template.

The template folder includes separate files for short word count, chapter count, basic and chapter-aware status, ships, genres, and the optional likeability score.
