The starter preset uses a simple book symbol so it can work for any fandom. You can keep it, choose another included colour, or edit the artwork to suit your library.

## Choose one of the included backgrounds

Download the [background image pack]({{ '/code/wordsandpics_classic_covers.zip' | relative_url }}) and unzip it. In Generate Cover, open **Select Image**, choose **Background image**, and select one of the SVG files.

The preset ZIP and background ZIP do different jobs: import `classics_preset.zip` as a Generate Cover setting, but unzip `wordsandpics_classic_covers.zip` and choose an individual SVG as an image.

## Customize an SVG

SVG files are editable image files. Open one in [Inkscape](https://inkscape.org/) or [Affinity](https://www.affinity.studio/) to change its colours, layout, text areas, or icon. Save your edited copy under a new name so the original remains available.

## Automatically choose custom covers

You can save several Generate Cover presets with different artwork, colours, or styles. FanFicFare can then use a story's metadata—such as its fandom, relationship, genre, or title length—to choose the appropriate preset automatically whenever it downloads or updates the story.

The **Choose a cover** section explains how to create these rules. Start with [Choose a cover by fandom]({{ '/choose/fandom/' | relative_url }}), then add more specific rules only if they are useful for your library.

## Limitations

The included files provide a starting point, not a complete set of fandom logos. Generate Cover can select different presets, but it does not invent or download artwork for you.
